# Moonshot Kimi (Kimi API 开放平台) — 免费额度领取教程

> Base URL: `https://api.moonshot.cn/v1` · 协议: OpenAI 兼容

## 1. 注册账号

1. 打开 [Kimi API 开放平台](https://platform.kimi.com)
2. 注册登录并完成个人实名认证（身份认证，非信用卡）

## 2. 创建 API Key

1. 进入 [API 密钥页面](https://platform.kimi.com/console/api-keys)
2. 创建并复制 MOONSHOT_API_KEY

## 3. 回到网关添加

1. 打开网关控制台 → 配置页 → 「现有提供商」面板
2. 找到 Moonshot Kimi 卡片，粘贴你的 Key
3. 点「确认添加」——免费模型自动导入

## 4. 免费模型说明

- 注册并完成实名认证后赠送 15 元代金券（一次性，无需支付方式）
- 代金券可用于：
  - `kimi-k2.6`
  - `kimi-k2.7-code`
- ⚠️ 代金券**不支持**旗舰 `kimi-k3`（默认模型），请勿用 k3 跑免费额度

## 5. 注意事项

- 15 元代金券为一次性、不循环，用尽后按量付费
- 旧的 `moonshot-v1-*` 系列 id 已停用，勿用
- API 域名仍是 `api.moonshot.cn/v1`（控制台域名已迁至 platform.kimi.com）
- 模型与计费以 [platform.kimi.com/docs](https://platform.kimi.com/docs/api/chat) 为准
