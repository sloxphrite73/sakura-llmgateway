# 阿里云百炼 (DashScope) — 免费额度领取教程

> Base URL: `https://dashscope.aliyuncs.com/compatible-mode/v1` · 协议: OpenAI 兼容

## 1. 注册账号

1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com)
2. 用阿里云账号登录并实名认证

## 2. 获取 API Key

1. 进入 [API Key 管理](https://help.aliyun.com/zh/model-studio/get-api-key)
2. 创建并复制 API key

## 3. 回到网关添加

1. 打开网关控制台 → 配置页 → 「现有提供商」面板
2. 找到 Alibaba Cloud Bailian 卡片，粘贴你的 Key
3. 点「确认添加」——免费模型自动导入

## 4. 免费模型说明

- 首次开通百炼即自动发放各模型 90 天新人免费额度（约 100 万 token/模型），无需绑卡
- 目录预置模型：
  - `qwen-plus`
  - `qwen-max`
- 走 OpenAI 兼容模式端点

## 5. 注意事项

- 免费额度仅限**北京（华北2）区域**，API key 区域专用不可混用
- 90 天额度一次性发放、不循环，到期或用尽后转按量付费
- 用 `qwen-plus` / `qwen-max` 这类不带版本号的别名最稳定
- 定价与免费额度以 [百炼文档](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope) 为准
