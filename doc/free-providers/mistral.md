# Mistral La Plateforme — 免费层领取教程

> Base URL: `https://api.mistral.ai/v1` · 协议: OpenAI 兼容

## 1. 注册账号

1. 打开 [https://console.mistral.ai](https://console.mistral.ai)
2. 邮箱注册（部分地区需手机验证）

## 2. 开通免费 Experiment 层

1. 登录后在「Plan」或订阅设置里选择 **Experiment 计划**（免费）
2. 可能需要绑定手机号验证

## 3. 创建 API Key

1. 进入 [API Keys 页面](https://console.mistral.ai/api-keys)
2. 点「Create new key」→ 复制保存

## 4. 回到网关添加

1. 打开网关控制台 → 配置页 → 「现有提供商」面板
2. 找到 Mistral 卡片，粘贴你的 Key
3. 点「确认添加」——模型自动导入

## 5. 免费模型说明

- Experiment 层免费可用（含速率与用量上限）：
  - `mistral-small-latest`
  - `open-mistral-nemo`
  - `codestral-latest`（专为代码生成，免费层也能调）
- 限额数据以控制台实时显示为准

## 6. 注意事项

- Experiment 层数据可能被用于模型训练，**敏感内容慎用**
- 想要隐私保障需升级付费层
