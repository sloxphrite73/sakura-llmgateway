# SiliconFlow 硅基流动 — 免费额度领取教程

> Base URL: `https://api.siliconflow.cn/v1` · 协议: OpenAI 兼容

## 1. 注册账号

1. 打开 [https://cloud.siliconflow.cn](https://cloud.siliconflow.cn)
2. 用手机号或微信登录，**注册即送体验额度**（以官网当日说明为准）

## 2. 创建 API Key

1. 登录后进入 [API 密钥页面](https://cloud.siliconflow.cn/account/ak)
2. 点「新建 API 密钥」→ 复制保存（只显示一次）

## 3. 回到网关添加

1. 打开网关控制台 → 配置页 → 「现有提供商」面板
2. 找到 SiliconFlow 卡片，粘贴你的 Key（多个 Key 每行一个）
3. 点「确认添加」——预置的免费模型会自动导入

## 4. 免费模型说明

- 下列模型**永久免费**（无需充值，有速率限制）：
  - `deepseek-ai/DeepSeek-R1-Distill-Qwen-7B`
  - `Qwen/Qwen2.5-7B-Instruct`
  - `THUDM/glm-4-9b-chat`
- `deepseek-ai/DeepSeek-V3` 等大模型消耗注册赠送的体验额度
- 免费模型以官网[价格页](https://siliconflow.cn/pricing)实时标注为准

## 5. 注意事项

- 免费模型有 RPM（每分钟请求数）限制，网关的智能冷却会自动处理 429
- 实名认证可提升部分限额
