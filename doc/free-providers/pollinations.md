# Pollinations — 无 Key 免费教程

> Base URL: `https://text.pollinations.ai/openai` · 协议: OpenAI 兼容 · **keyless**

## 1. 直接可用（无需注册）

- Pollinations 匿名即可调用，**不填 Key 也能跑**
- 匿名调用有频率限制（每秒/每日请求数较低）

## 2. 可选：注册免费 token 提升限额

1. 打开 [https://auth.pollinations.ai](https://auth.pollinations.ai)
2. GitHub 登录即可获取 token
3. 把 token 粘贴到网关卡片的 Key 输入框（作为限额提升凭证）

## 3. 回到网关添加

1. 打开网关控制台 → 配置页 → 「现有提供商」面板
2. 找到 Pollinations 卡片
3. **Key 留空或粘贴 token** → 点「确认添加」即可

## 4. 免费模型说明

- `openai`（GPT 系列小模型）、`openai-fast`、`openai-large` 均可匿名调用
- 模型别名会随时间调整，以 [text.pollinations.ai/models](https://text.pollinations.ai/models) 实时列表为准

## 5. 注意事项

- 匿名层限速严格，建议注册 token 后再大量使用
- 该服务面向社区，稳定性不如商业 API，重要任务请配置其他提供商兜底
