# SambaNova (SambaCloud) — 免费额度领取教程

> Base URL: `https://api.sambanova.ai/v1` · 协议: OpenAI 兼容

## 1. 注册账号

1. 打开 [SambaCloud](https://cloud.sambanova.ai/)
2. 注册登录，无需信用卡

## 2. 创建 API Key

1. 在 SambaCloud 控制台进入 API Keys 页面
2. 创建并复制 API key

## 3. 回到网关添加

1. 打开网关控制台 → 配置页 → 「现有提供商」面板
2. 找到 SambaNova 卡片，粘贴你的 Key
3. 点「确认添加」——免费模型自动导入

## 4. 免费模型说明

- 免费层每模型 20 RPM / 20 RPD / 20 万 TPD，每日重置，无需绑卡
- 目录预置模型：
  - `Meta-Llama-3.3-70B-Instruct`
  - `DeepSeek-V3.1`
  - `gpt-oss-120b`
- 专用推理芯片，速度极快

## 5. 注意事项

- 模型 id 区分大小写，原样使用即可
- 免费层日请求量有限，超限返回 429，建议多供应商兜底
- 模型列表以 [docs.sambanova.ai](https://docs.sambanova.ai/docs/en/models/sambacloud-models) 为准
