# AI21 — 免费额度领取教程

> Base URL: `https://api.ai21.com/studio/v1` · 协议: OpenAI 兼容

## 1. 注册账号

1. 打开 [https://studio.ai21.com](https://studio.ai21.com)
2. 用邮箱/社交账号自助注册，**新账号即赠 $10 免费额度**（3 个月有效，**无需绑卡**即可开始调用）

## 2. 创建 API Key

1. 登录后进入 API Keys 页面（Studio 控制台）
2. 创建并复制 API Key（Studio API key，作 Bearer 鉴权）

## 3. 回到网关添加

1. 打开网关控制台 → 配置页 → 「现有提供商」面板
2. 找到 AI21 卡片，粘贴你的 Key（多个 Key 每行一个）
3. 点「确认添加」——预置的免费模型会自动导入

## 4. 免费模型说明

- 可用额度调用 Jamba 系列（Mamba-Transformer 混合架构，256K 上下文）：
  - `jamba-large`
  - `jamba-mini`
- $10 额度用尽或 3 个月到期后，才需绑定支付方式继续使用

## 5. 注意事项

- 免费额度为**一次性**赠送（3 个月有效），非按月循环
- 调用走 OpenAI 兼容端点：`POST https://api.ai21.com/studio/v1/chat/completions`
- 额度耗尽前都不会扣费；网关的智能冷却会自动处理 429
