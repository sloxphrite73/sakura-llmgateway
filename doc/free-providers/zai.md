# Z.AI（智谱 GLM）— 免费额度领取教程

> Base URL: `https://api.z.ai/api/paas/v4` · 协议: OpenAI 兼容

## 1. 注册账号

1. 打开 [https://z.ai](https://z.ai)（智谱海外站；国内站为 bigmodel.cn，接口与 Key 通用性以官网说明为准）
2. 邮箱或第三方登录注册

## 2. 创建 API Key

1. 进入 [API Key 管理页](https://z.ai/manage-apikey/apikey-list)
2. 点「新建 API Key」→ 复制保存

## 3. 回到网关添加

1. 打开网关控制台 → 配置页 → 「现有提供商」面板
2. 找到 Z.AI 卡片，粘贴你的 Key
3. 点「确认添加」——`glm-4-flash` 等免费模型自动导入

## 4. 免费模型说明

- **GLM-4-Flash / GLM-4-FlashX / GLM-4.5-Flash 系列：免费**（有并发与频率限制）
- Flash 系列定位为高速轻量模型，日常对话与简单任务够用
- 高端模型（GLM-4.5/4.6 等）需要充值或使用赠送额度

## 5. 注意事项

- Flash 系列免费但限速，适合多 Key 池分流
- 模型名以[官方模型列表](https://docs.z.ai)为准，网关内也可随时手动追加
