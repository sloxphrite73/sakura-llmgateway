## 2. 本地构建

### Windows 可执行文件

```powershell
cd llm-gateway
cargo build --release        # 产物：target/release/llm-gateway.exe
```

**关键坑（rust-embed 不追踪静态文件）**：只改 `static/index.html` / `sakura-ui.css` 时，必须 touch 一个 .rs 文件（惯例 touch `src/ui.rs`）再 build，否则二进制里嵌的还是旧 UI。Windows exe 和 Android 交叉编译都受此影响。

构建前杀掉运行中的实例，否则链接器报 os error 5：

```powershell
Get-Process llm-gateway,mock_upstream -ErrorAction SilentlyContinue | Stop-Process -Force
```

### Android APK

```powershell
.\android\build-local.ps1            # 构建 release APK
.\android\build-local.ps1 -Install   # 构建 + adb 安装到已连接设备
```

## 3. 核心设计不变量（改动时不得违反）

这些是用多次线上事故换来的，详见 `PASS.md`：

1. **容量真相只来自配置**。每 Key 容量 = seed_rpm > 提供商 rpm_limit/tpm_limit 按 Key 数拆分。**不要**从 429 采样反推容量——429 的「rpm 或 tpm 任一触发」语义证明采样无法区分二者，历史上这么做过三次，每次都把利用率钉死在 100%。

2. **冷却链**：Retry-After 头 → 每 Key cooldown_secs 覆盖 → 60s 窗口推算（用量老化排空 ×0.9 偏低取，钳制 [2,900]s）→ 全局默认。探测器（prober）**已整体移除且不得复活**——它本身消耗 RPM 额度，且「二分探测失败时写入编造的 learned_cooldown」曾导致第二天整池瘫痪。

3. **零失败 hold**：全冷却时挂起等待最近恢复的 Key（上限 `max_hold_secs`，默认 120s），无尝试计数器——hold 预算严格消耗、就绪集严格缩小，天然终止。

4. **比较器顺序**：有效优先 → 非冷却优先 → 用户排序栈 → idx 游标轮转。排序键 K = 平滑成功率 × headroom。

5. **配额耗尽的 429**（"entitlement exhausted"、"insufficient_quota"、"余额不足" 等 body 标记）→ `mark_invalid` 30 分钟，不是短冷却。

6. **统计合并进 gateway.json**（stats 字段），不落第二个文件；导入配置时统计被采纳而非丢弃。

## 4. 控制台 UI 约定

- 单文件原生 HTML/JS，**没有前端构建链**。改完用 `node --check` 校验内嵌脚本（一个飘失的反引号曾导致白屏 APK）。
- 轮询：API Key 页和统计页 1s；统计页是 change-detected 渲染（payload 字节不变不重渲），重渲时必须保留主区 scrollTop 和柱状图 `.hist-scroll` 的 scrollLeft。
- 中英双语文案走 `t()` 函数；新增文案两个语言都要加。
- Android 专属能力通过 `window.SakuraAndroid` JS 桥（电池优化/自启动跳转、横屏锁定、状态栏主题），UI 里用 `window.SakuraAndroid ? ... : ''` 门控。

## 5. 测试

```powershell
cd llm-gateway
cargo test                                    # 单元测试
cargo run --bin mock_upstream                 # 假上游：127.0.0.1:9001
```

mock_upstream 的 Key 约定：`sk-bad` 恒 429（Retry-After: 2）、`sk-dead` 恒 401、`sk-slow` 慢响应、`sk-window-<N>` 模拟每 Key 窗口、`sk-poor` 配额耗尽。配合 `test/gateway.json`（gitignored，自建）做端到端验证。

## 6. API 参考

### 网关 API

| 接口 | 方法 | 说明 |
|------|------|------|
| `/v1/chat/completions` | POST | Chat Completions（流式 + 非流式，图片） |
| `/v1/messages` | POST | Anthropic Messages（流式 + 非流式，tools / 图片） |
| `/v1/messages/count_tokens` | POST | Token 计数（Anthropic 上游透传，OpenAI 上游本地估算） |
| `/v1/models` | GET | 聚合模型列表（含 `supports_images` 声明） |

### 控制台 API

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/status` | GET | 实时配置 + Key 池状态 + 版本号 |
| `/api/stats` | GET | 请求统计（总量、24h 柱状图、按 Key/提供商/模型） |
| `/api/config/export` | GET | 下载 `gateway.json`（含统计） |
| `/api/config/import` | POST | 配置 + 统计热重载（先验证后切换） |
| `/api/providers` | GET / POST | 列出 / 创建提供商 |
| `/api/providers/{id}` | PUT / DELETE | 更新 / 删除提供商 |
| `/api/providers/{id}/rate-limits` | PUT | 设置提供商 RPM/TPM 限额 |
| `/api/providers/{id}/price-table` | PUT | 设置每模型输入 + 输出价格（`{table, output_table}`） |
| `/api/providers/{id}/keys` | POST | 添加 Key |
| `/api/providers/{id}/keys/{key_id}` | DELETE / PUT | 删除 Key / 更新指标 seed |
| `/api/providers/{id}/models` | POST | 添加托管模型 |
| `/api/providers/{id}/models/{model_id}/context-length` | PUT | 设置模型上下文长度 |
| `/api/providers/{id}/models/{model_id}/supports-images` | PUT | 切换图片输入支持 |
| `/api/keys/{key_id}/cooldown` | DELETE | 清除 Key 冷却 |
| `/api/strategy/dry-run` | POST | 预览某模型的路由 |
| `/api/settings` | PUT | 更新全局设置 |

## 7. 常见任务速查

| 任务 | 入口 |
|------|------|
| 加排序键 | `config.rs` SortKey 枚举 + `strategy.rs` 比较器 + UI 排序下拉 |
| 加控制台 API | `admin.rs` 加 handler + `main.rs` 注册路由 + UI `api()` 调用 |
| 改冷却行为 | `state.rs::mark_rate_limited` / `window_recovery_secs`（先读 §3.2） |
| 加免费上游 | 编辑 `llm-gateway/free-catalog.json`（远程刷新会拉到最新） |
| 改协议翻译 | `protocol.rs`，注意流式 SSE 路径也要同步 |

遇到问题先翻 `PASS.md`——你踩的坑大概率前人踩过并写了答案。
